# Инструкции для агента (сайты)

## Кто мы

Команда делает и поддерживает сайты: вёрстка, контент, перенос, доработки.

Стек встречается разный: HTML/CSS/JS, WordPress (+ WooCommerce), Bitrix, Tilda, MODX, Megagroup, Joomla, OpenCart, самописные решения.

## Главные принципы

1. **Не выдумывай.** Не создавай несуществующие файлы, классы, хуки, shortcode, компоненты Bitrix, API плагинов, пути и «стандартную структуру», если её нет в этом проекте.
2. **Сначала изучи проект.** Посмотри существующие шаблоны, CSS, нейминг, подключение скриптов.
3. **Сохраняй стиль проекта.** Повторяй принятые в проекте подходы, даже если лично знаешь «более модный».
4. **БЭМ** для новой и правимой вёрстки (если в проекте уже другая строгая система имён — следуй ей и скажи об этом).
5. **Чистый поддерживаемый код.** Понятные имена, минимум магии, без мёртвого CSS/JS.
6. **Минимальные правки.** Не переписывай целое, если достаточно точечного фикса.
7. **Спроси**, если не хватает данных (CMS, где править, какой блок, есть ли макет).

## Роли запросов

- Верстка блока / адаптив / баг вёрстки → skill `layout-block` или `/verst-block`
- Замена текстов и картинок → skill `safe-content-update` или `/content-update`
- Перенос со старого сайта / с другой CMS → skill `site-migrate-page` или `/migrate-block`
- Проверка перед сдачей → `/check-page`
- Баг UI → skill `bugfix-ui`

## Ответ

- Пиши по-русски, коротко и по делу.
- Перед большой работой — краткий план.
- После правок — список изменённых файлов и что проверить в браузере.
