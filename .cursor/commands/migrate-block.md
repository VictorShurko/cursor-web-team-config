Запусти сценарий переноса.

Сначала план и вопросы, код не пиши, пока не скажут «начинай».

Обязательно:
- эталон 1 в 1 по виду и поведению;
- код источника не копировать — верстать заново;
- БЭМ / схема проекта, семантика, адаптив;
- ассеты только локально, без CDN источника;
- сквозные блоки в отдельных файлах;
- ничего не выдумывать;
- порядок: шапка/меню/футер → главная → остальные страницы → финальные итерации.

В конце: список сделанного, что сверено, что осталось.
