# Вёрстка блока

## Перед работой

1. Определи платформу проекта по файлам (HTML, WP, Bitrix и т.д.) — не угадывай.
2. Прочитай существующие соседние блоки и CSS: нейминг, отступы, кнопки, сетка.
3. Если нет макета/скрина/точного места вставки — спроси.
4. Ничего не выдумывай: классы, файлы и зависимости только из проекта или явной задачи.

## Делай

1. Вставь/правь блок в реальном файле шаблона проекта.
2. Имена классов — по БЭМ и схеме проекта.
3. Семантика HTML + базовый a11y (`alt`, focus, button/link по смыслу).
4. Адаптив по брейкпоинтам проекта (иначе ориентиры 320/768/1024/1440).
5. Без новых библиотек и без глобального рефакторинга «заодно».

## Результат

- Список изменённых файлов
- Кратко: какие BEM-блоки использованы
- Что проверить в браузере (десктоп/мобилка, ховеры, длинный текст)
