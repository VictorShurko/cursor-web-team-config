# Безопасное обновление контента

1. Найди точные места контента в проекте (не выдумывай пути админки/файлов).
2. Замени только контент: тексты, `src`, `href`, `alt` по задаче.
3. Не меняй структуру DOM, классы, id, PHP/JS.
4. Если файла изображения нет в проекте — сообщи, не подставляй вымышленный путь.
5. Если контент переполняет блок — предупреди.
6. В конце: что изменено и что проверить на странице.
