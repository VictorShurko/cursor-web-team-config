# Фикс UI-бага

1. Уточни/используй: где баг, ширина экрана, браузер, ожидаемое поведение.
2. Найди причину в реальных HTML/CSS/JS файлах проекта. Не гадай пачкой несвязанных правок.
3. Исправь минимально.
4. Проверь, что соседние блоки теми же правками не ломаются (по коду).
5. В ответе: причина → фикс → файлы → что перепроверить.
6. Если воспроизвести/подтвердить нельзя — так и напиши, не имитируй проверку.
