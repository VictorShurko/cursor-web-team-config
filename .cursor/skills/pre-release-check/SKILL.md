# Проверка перед сдачей

Проверь по коду проекта (и укажи, что не проверялось в браузере, если не запускал):

## Критично

- Битые пути к изображениям/скриптам/стилям в изменённых местах
- Сломанные важные ссылки и кнопки в затронутых блоках
- Явные поломки адаптива в изменённой вёрстке
- Случайная порча CMS-логики (WP/Bitrix/и т.д.)

## Желательно

- БЭМ-согласованность новых классов
- Семантика и базовый a11y (`alt`, focus, заголовки)
- Лишний код после правок
- Контентное переполнение

Формат ответа:
1. Критично
2. Желательно
3. Что не проверялось
